# Analysis context

This folder contains review outputs and analytical notes used for AI handoff and project assessment.

## Canonical file

- `../REVIEW-FINDINGS.md` — review summary and assessment notes

## Purpose

Use this folder for:
- review conclusions
- risk summaries
- AI handoff commentary
- deeper analysis of repository quality and consistency

## Important rule

This is evaluative material, not source-of-truth repository state. It must never be treated as the project specification or as a substitute for the live code and live git state.
